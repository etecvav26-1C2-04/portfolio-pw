Este site foi desenvolvido como projeto escolar na disciplina de Desenvolvimento de Web-Site.


O objetivo é apresentar informações turísticas sobre Jundiaí de maneira simples, organizada e acessível.


Foram utilizados HTML, CSS e JavaScript no desenvolvimento.
