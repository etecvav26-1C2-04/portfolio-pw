Habilidades técnicas

Conhecimentos que venho desenvolvendo e aplicando na criação de sites, interfaces digitais e projetos durante minha formação.

Desenvolvimento Front-end

Criação de páginas e interfaces web, trabalhando com a estrutura, aparência, organização dos elementos e funcionalidades dos sites.

HTML

Estruturação de páginas, organização de conteúdos e utilização de elementos para construir a base dos sites.

CSS

Criação de layouts, aplicação de cores, tipografia, espaçamentos e organização visual das páginas, incluindo responsividade.

JavaScript

Aplicação de lógica de programação para desenvolver interações e adicionar funcionalidades às páginas web.

UI/UX Design

Criação de interfaces organizadas e intuitivas, considerando a aparência visual, a facilidade de navegação e a experiência do usuário.

Git e GitHub

Organização de repositórios, controle de versões, acompanhamento de alterações no código e colaboração em projetos em equipe.

Meu processo de desenvolvimento

Etapas que utilizo como referência para transformar uma ideia em um projeto web.

01

Planejamento

Compreender a proposta, definir os objetivos e organizar as ideias antes de começar.

02

Estruturação

Construir a estrutura das páginas e organizar os conteúdos utilizando HTML.

03

Design e estilização

Definir cores, fontes, layouts e estilos para criar uma identidade visual para o projeto.

04

Testes e ajustes

Verificar a navegação, testar funcionalidades e corrigir possíveis problemas encontrados.
